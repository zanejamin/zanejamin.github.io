Space Invaders Knockoff

A boss-rush take on the arcade classic - five boss types with distinct attack patterns, escalating alien waves, and a level system. Originally written in Python with pygame; this is a browser port of that game's logic so you can play it without installing anything.

Controls

  • ← → or A / D - move
  • Space - fire
  • Enter - continue
  • Esc - back to menu

The bosses

  • Juggernaut - triple shot, heavy HP
  • Hive Mother - summons orbiting minions
  • Teleporter - blinks across the screen
  • Laser Core - charges a lock-on beam
  • Bomber - wide-radius explosives

About the port

The original is Python/pygame. Browsers can't run that directly, so the game logic was ported to JavaScript and canvas - same bosses, waves, sprites and audio. The Python source is linked above.
