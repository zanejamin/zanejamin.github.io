Space Invaders Knockoff

A boss-rush arcade game I wrote from scratch in Python with pygame for my Coding Odyssey course: sprite animation, collision detection, and the game loop all written by hand. It has five boss types with distinct attack patterns - a triple-shot juggernaut, a hive mother that summons orbiting minions, a teleporter, a laser core that charges a lock-on beam, and a bomber with wide-radius explosives - plus escalating alien waves and a boss every fifth level. Browsers cannot run Python directly, so I ported the game logic to JavaScript and canvas to make it playable here without installing anything.

Bible App Prototype

An app concept designed to help people who doom-scroll too much redirect that time into scripture reading. The idea is to meet the habit where it already lives: short, frictionless sessions that open instantly and pick up where you left off, rather than asking someone to commit to a long reading plan they will abandon by the second week. This is a design and UX prototype rather than a shipped app, and the write-up walks through the reasoning behind each screen.
