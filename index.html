Bible Clasp (Android App)

A native Android app in Kotlin and Jetpack Compose that redirects doom-scrolling into scripture reading. You choose which apps to lock; opening one raises a verse instead. Reading verses earns minutes into a shared time bank that those apps then spend, and an optional accountability partner is notified if protection is disabled or bypassed. The interesting engineering is in the constraints: foreground detection polls UsageStatsManager rather than using an AccessibilityService, because Google restricts that API to genuine accessibility use and app-locking is a fast route to a Play Store rejection. That trade costs a one second worst-case detection window. Uninstall protection is a device admin registration, and the pure logic is split out from the Android framework so it can be unit tested, currently 75 tests passing.

End-to-End Encrypted Group Chat

Real-time encrypted chat for up to 8 users, with peer-to-peer WebRTC voice. Built on Node.js and Socket.io using the browser's native Web Crypto API, no crypto libraries. Per-pair ECDH key exchange with HKDF ratchets gives every message a fresh key, and the server only ever relays ciphertext.
